# Explicit project memory

Supported types: FACT, DECISION, WARNING, NOTE, CONVENTION, INCIDENT, TODO. Scopes are repository, directory, file and symbol; global scope is rejected. Content is explicitly supplied, not inferred from code or automatically generated by a model.

`remember` creates a record; `supersedes` replaces an active same-project record transactionally and links it to the new record. The old record stays SUPERSEDED. CLI `memories --archive <id>` archives a same-project record. Search returns ACTIVE records unless explicitly asked for inactive ones.

`clean --yes` deletes only graph data. `remove --yes` removes the selected registration and its memory. Both operations are scoped and acquire the project index lock. Do not use remove when you only want to rebuild code structure.
