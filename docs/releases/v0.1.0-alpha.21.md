# v0.1.0-alpha.21 — Reliable Windows command setup

Integra CodeMemory brings local code intelligence and explicit project memory to Codex and Claude Code. This release fixes a frustrating Windows setup issue: `codememory` disappearing when a terminal is reopened.

## Highlights

- **Persistent Windows PATH:** installation and updates register the shared CLI directory in the current user's PATH and verify the write.
- **Targeted cleanup:** duplicate shared entries, an incorrectly added `cli` directory, and old release `bin` / `cli\bin` entries under the same installation are removed. Unrelated entries and machine PATH are preserved.
- **PowerShell session refresh:** the installer refreshes its invoking session and notifies Windows about the environment change. Existing terminal/IDE processes still need restarting after a CLI update.

## Update

From a shared CLI installation:

```sh
codememory update --version v0.1.0-alpha.21
```

If Windows cannot find the command, invoke the launcher directly:

```powershell
& "$env:LOCALAPPDATA\integra-code-memory\cli\bin\codememory.cmd" update --version v0.1.0-alpha.21
```

Close existing terminal windows or restart the IDE hosting your terminal. Then run `codememory --version` and reconnect open Codex/Claude MCP connections. Existing project scopes and index data are preserved. No database migration is introduced by this release.

Alpha.16 and older installations need the [one-time shared-runtime migration](https://github.com/iOwsla/integra-codebase-memory/blob/main/docs/installation.md#shared-runtime-updates).

## New to CodeMemory?

Follow the [quick start](https://github.com/iOwsla/integra-codebase-memory#quick-start) from the project you want to index. Bun and Git are prerequisites; the bootstrap can prepare Docker and dedicated PostgreSQL. These are source releases, not standalone executables.

Existing capabilities include JS/TS call and reference analysis, Prisma schema/model usage, focused source retrieval, explicit project memory and bounded dead-code/duplication candidates. See the [documentation](https://github.com/iOwsla/integra-codebase-memory/blob/main/docs/README.md).
